# Privacy Notice

This Twitch Extension displays static images, titles, and informational text for viewers.

The extension does not intentionally collect, store, or share personal information from viewers.

The extension does not use cookies, analytics services, or external databases to track user activity.

Viewer interactions, such as selecting navigation tabs, are processed locally within the extension and are not stored or transmitted to the extension developer.

The extension uses Twitch's Extension Helper library to operate within the Twitch platform. Twitch may process information according to its own privacy policies.

For information about Twitch's data practices, please visit https://www.twitch.tv/p/legal/privacy-notice/.
